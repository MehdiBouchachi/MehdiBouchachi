## About me

I'm a **software engineering student and freelance developer** with experience building web applications, collaborating on community platforms, and deploying services to real servers.

My work spans **frontend development, backend APIs, database design, deployment, and IoT systems**. I care about clean interfaces, maintainable architecture, and the less glamorous but essential part of software engineering: making things run reliably outside a development machine.

- **Freelance Web Developer** since 2023, working on client-facing websites and applications.
- **Former Front-End Team Lead & React Instructor** at IT Community (2023–2024).
- **Hands-on deployment experience** with Next.js, Node.js, Nginx, Docker, and Windows Server.
- **Interested in offline-first systems**, distributed device communication, and practical software architecture.
